# The tool catalog

Every Flux capability is **one typed Python function exposed three ways**: a plain library
call, a CHIA orchestration node (distributed execution, resource matching, fault tolerance --
on Ray), and an MCP tool an agent can call over the wire. There is no code-generation layer;
each surface is a hand-written wrapper over the same definition.

The pages in this section are the **fourth surface**: they are generated by introspecting the
MCP server's own registrations -- the very same introspection the [omni loop](../demos/omni.md)
plans over -- so the signatures, defaults and parameter docs here are exactly what an agent
sees, and they cannot drift from the code. A test regenerates these pages and fails the build
when they disagree with the live surface.

The tools compose: a [loop](loops.md) is itself one call, but it is built from the same
[searches](search.md), [evaluations](evaluate.md), [generators](generate.md),
[records](campaign.md) and [knowledge](knowledge.md) that are offered individually -- so an
agent (or a person) can run a whole study, or wire the pieces into a loop of their own as the
[guide](../guide/build-your-own.md) describes.

| page | what is on it |
|---|---|
| [Design loops](loops.md) | complete searches, one call each: the per-application loops plus the reference agentic loop |
| [Search and sweeps](search.md) | single-axis and joint searches, dynamic-shape and MoE-routing sweeps |
| [Campaigns and records](campaign.md) | stepped campaigns, results by lineage, leaderboards, the public corpus |
| [Evaluation and calibration](evaluate.md) | score a candidate through a real backend, calibrate, check validity and conformance |
| [Generation and synthesis](generate.md) | architecture candidates, RTL and SystemC modules, real synthesis on ASAP7 |
| [Knowledge and protocols](knowledge.md) | corpus retrieval, mined facts, protocol structure with provenance |

Each tool shows its required parameters up front in a table; the optional ones -- which
dominate, several tools take fifteen or more -- are folded into a collapsible table with
their defaults. Parameter descriptions are the first sentence of what an agent is told, so
the pages and the agent surface cannot disagree.
