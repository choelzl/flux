# MAC array: the processing element

**The problem.** The multiply-accumulate element (PE) of a processing array: 8 products summed
per cycle at int8. Find the smallest PE that runs at 1000 MHz once placed on ASAP7.

The search covers every combination of:

| knob | choices |
|---|---|
| multiplier | behavioral, shift-and-add, radix-4 Booth, Wallace tree, plus any a model invented |
| reducer | chain, tree, carry-save |
| pipeline | 0 to 3 register stages |

That is 48 designs. Each is generated by code, proved correct in Verilator, synthesised by Yosys;
the best are placed by OpenROAD.

## Run it

```bash
flux task run applications/macarray/macarray.problem.yaml --passes 1 --steps 1               # no model
flux task run applications/macarray/macarray.problem.yaml --passes 1 --steps 1 --screen-only # synthesis only
flux task run applications/macarray/macarray.problem.yaml                                    # with invention, until stopped
```

## What the document says

| key | value |
|---|---|
| `params` | `lanes: 8`, `target_mhz: 1000`, `multipliers`, `include_invented: true`, `preserve_fmax: false` |
| `objectives` | `fmax_mhz` at least 1000, then least `area_um2` |
| `stages` | `screen` (Yosys), `confirm` (OpenROAD placement) |
| `flow` | `dse: sweep`: every point is tried |
| `budget` | `steps: 4`: one sweep, then three rounds where a model invents a new multiplier |
| `world` | `flux_macarray.world:World` |

## What the model does

After the sweep, the model is shown each built-in multiplier's measured speed and area and asked
for a multiplier the list does not contain. Flux refuses one that is sequential or just `a * w`,
then tests it in Verilator and feeds errors back. Every multiplier that passes joins the menu of
later runs.

## Changing the ask

For 16 lanes at 1.5 GHz: copy the document, set `id: mac16`, `params.lanes: 16`,
`params.target_mhz: 1500` and the `fmax_mhz` goal to 1500. `preserve_fmax: true` instead asks
how much area can go while keeping the current design's clock.

## What it needs

The tool shell (Verilator, Yosys, OpenROAD). A model only for the invention rounds; without one
they report themselves skipped and the sweep's decision stands.
