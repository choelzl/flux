# MAC array

**The MAC processing element's microarchitecture, on real ASAP7 numbers.** The array is given
-- `--lanes` products summed per cycle at the precision the workload declares (int8 by
default). What is searched is inside the PE:

| knob | values | what it changes |
|---|---|---|
| multiplier | behavioral, shift-and-add, radix-4 Booth, Wallace tree, plus anything a model invented | how each product is formed |
| reducer | chain, tree, carry-save | how the products become one sum |
| pipeline | 0-3 | register stages: products, output, a cut through the reduction |
| mapping | delay, area | what ABC is told to optimise -- same RTL, different netlist |

96 points. Every one is generated by code, **verified by Verilator** against golden vectors
seeded from the workload (with its latency checked against the stages it claims), **screened**
by Yosys + OpenSTA (seconds, optimistic, identical in method for every candidate), and the
finalists spread along the fmax-vs-area frontier are **placed by OpenROAD** -- the only rung a
report may quote.

```bash
nix develop .#physical --command python3 applications/macarray/demo.py                  # 1 GHz target
nix develop .#physical --command python3 applications/macarray/demo.py --target-mhz 1500 --lanes 16
nix develop .#physical --command python3 applications/macarray/demo.py --invent 2 --screen-only
```

The decision is the **smallest PE that makes the target clock**; with `--preserve-fmax` the
target is the incumbent's own measured clock on each rung, so the answer is how much area can
go while the clock stays. The frontier is printed whole -- each row faster than everything
smaller, saying what its extra area bought -- so a reader with a different clock picks their
own point. `--db` accumulates measurements keyed by tool fingerprints and exact source; a
resumed run re-measures nothing.

## What the model does

Nothing, by default: a 96-point space is screened exhaustively in minutes and needs a judge,
not a proposer. `--invent N` asks the local model for N **multiplier structures the enumeration
does not contain** -- after the screen, so the prompt carries each built-in's measured worst
path and area from this very run as the number to beat. A proposal is refused before any tool
runs if it is sequential or just the behavioral multiply already in the space; then it faces
Verilator at the sign corners, with compile errors and failing vectors fed back, bounded. Every
multiplier that passes is kept and joins the menu of every later run, where the screen ranks
it against the four built in.
